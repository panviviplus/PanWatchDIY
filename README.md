# 盯盘侠 PanWatch

**自托管 AI 盯盘助手 · 集成 [TradingAgents](https://github.com/TauricResearch/TradingAgents) 多 Agent 投资决策** — A 股 / 港股 / ETF / 美股实时监控、持仓管理、智能分析、通知推送。

最近盯盘上瘾，找了个开源项目，但是功能不太满足，自己DIY了一波：

## 亮点功能：
1. 能盯ETF、股票，牢A、港、美盘都能；
2. 能自由组合，设定关注规则，达到什么条件就推送通知；
3. 接了TradingAgents——一个开源的交易AI Team工具，任何下单操作都可以AI分析；
4. 支持盘前、盘中、盘后分析“异动”，总结操作建议，并及时推送；
5. 全部数据本地化；

详细内容见源仓库：https://github.com/TNT-Likely/PanWatch
